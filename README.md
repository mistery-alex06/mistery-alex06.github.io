# 🌐 Portfolio — Alessio Casarotto

Codice sorgente del mio portfolio personale, online su **[mistery-alex06.github.io](https://mistery-alex06.github.io)**.

Sono Alessio Casarotto, studente di Ingegneria dell'Automazione al Politecnico di Milano e sviluppatore software per il Polimi Sailing Team. Il sito raccoglie i miei progetti, il percorso di studi e i modi per contattarmi.

## 🛠️ Stack Tecnico

Sito statico realizzato in **HTML, CSS e JavaScript puro**, senza framework né dipendenze esterne.

| File | Contenuto |
|---|---|
| `index.html` | Struttura della pagina: Hero, Chi Sono, Skill, Progetti, Esperienza, Contatti |
| `index.css` | Design system: palette colori bianco/oro, glassmorphism, animazioni, layout responsive |
| `index.js` | Menu mobile, animazioni allo scroll, effetto tilt sulla card Hero, validazione e invio del form di contatto |

## ✉️ Form di Contatto

Il modulo "Iniziamo a Collaborare" invia i messaggi via [Formspree](https://formspree.io), senza bisogno di un backend proprio.

## 🚀 Deploy

Il sito è pubblicato tramite **GitHub Pages** direttamente da questo repository (branch `main`, root).
